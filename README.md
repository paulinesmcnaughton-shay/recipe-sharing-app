# GatherBites

A recipe sharing app built to explore full-stack product development 
with AI-assisted tools.

**Live app:** https://recipe-sharing-app-sigma-brown.vercel.app

![GatherBites screenshot](public/screenshot.png)

## About

GatherBites lets users save, upload, and discover recipes in one 
clutter-free space. Built as a personal project to practice shipping 
a real product end to end, from design in Figma to a live, 
authenticated web app.

## What I built

- Recipe browsing and discovery feed
- User authentication with persistent sessions
- Save favorites to a personal profile
- Upload recipes with external links
- Responsive UI with a clean, dark aesthetic

## How I built it

Designed in Figma, then built in Cursor using Claude as a coding 
collaborator. This is how I work as a founding designer: I own the 
full product, from the design decisions to the deployed experience.

## Stack

- Next.js + TypeScript
- Tailwind CSS
- Supabase (database + auth)
- Vercel (deployment)
- Built with Cursor + Claude
